Indexing Strategy (validated):
- Prisma indexes on product/status/category/tenant combinations, issue/status, import/edit operations, plan usage, audit.
- SQL indexes for connector timeline/status lookups and idempotency uniqueness.
- SQL indexes for media assets and dashboard snapshots/metrics.

Key Constraints:
- Product soft-delete query filtering via middleware unless bypass flag used.
- Product purge route only after soft delete.
- Connector submission idempotency unique index:
  (tenant_key, installation_id, idempotency_key)
- Connector webhook dedupe unique:
  (installation_id, external_event_id)

Data Versioning:
- Product optimistic versioning with expectedVersion.
- ChannelMappingTemplate version field.
- Connector definition connector_version field.
