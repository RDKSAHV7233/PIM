Shopify Connector
Setup & Publishing Guide

Connect your Vexa PIM to Shopify in minutes using a custom app token, then publish products directly from PIM to your store.

Vexa PIM · Shopify Integration · May 2026

Before You Begin — Prerequisites

  • Admin or Manager role in Vexa PIM
  • Shopify store with Admin access
  • Custom app created in Shopify Admin
  • Admin API Access Token (SHPAT) from that app
  • At least one sales channel / publication in Shopify
  • Products in Approved or In Review status in PIM
Phase 1 — Install the Connector
Shopify Admin

Create a Custom App in Shopify

In Shopify Admin, go to Apps → Develop apps → Create an app. Give it a name (e.g. Vexa PIM). Under Configuration → Admin API access scopes, enable at minimum: read_products, write_products, read_publications, write_publications.

ℹ️

You only need to create this custom app once per Shopify store.

Shopify Admin

Generate the Admin API Access Token (SHPAT)

Inside your new app, click API credentials → Install app. After installation, click Reveal token once under Admin API access token. Copy the token — it starts with shpat_.

⚠️

Shopify shows this token only once. Store it in a password manager before leaving the page.

Vexa PIM

Open the Connector Setup Page

In Vexa PIM, navigate to Channels → Connectors in the left sidebar. Find the Shopify tile and click Set Up (or Install). You will land on the connector setup form.

Vexa PIM

Enter an Account Alias

In the Account Alias field, type a short, human-readable name for this Shopify store (e.g. main-store or vishaltest112). This label appears in connector lists and export history.

ℹ️

Use lowercase letters, numbers, and hyphens only. Avoid spaces.

Vexa PIM

Enter Your Store Domain

In the Store Domain field, type your Shopify store's myshopify domain, e.g. your-store.myshopify.com. Do not include https:// — just the hostname.

Vexa PIM

Paste the Admin API Access Token (SHPAT)

In the Admin API Access Token (SHPAT) field, paste the shpat_… token you copied in Step 2. The field is masked for security. Leave the Client ID field blank — it is only needed for managed OAuth installs.

✅

Providing the SHPAT completes authorization immediately — no OAuth redirect required.

Vexa PIM

Submit the Setup Form

Click Install Connector (or Save). Vexa PIM sends the credentials to the API, creates the installation record, and calls back Shopify to validate the token. On success you are redirected to the connector's Overview tab.

⚠️

If you see an error, double-check that the store domain matches the store where you created the custom app, and that the SHPAT was copied in full.

Phase 2 — Verify & Configure
Verify

Confirm Connection on the Overview Tab

On the connector Overview tab, confirm that no amber warning banner appears at the top of the page. A warning banner means OAuth has not been finalized — go back to Step 6 and re-enter the SHPAT. If the page is clean, the connector is fully authorized.

Vexa PIM

Open the Credentials Tab

Click the Credentials tab. This tab performs a live fetch of your Shopify publication channels each time it loads. Wait a moment for the list to populate.

ℹ️

If no channels appear, reload the page. The tab header reads Reload to refetch channels → — click it to trigger a fresh fetch from Shopify.

Vexa PIM

Select a Publication Target

From the list of channels fetched from Shopify (e.g. Online Store, Point of Sale), tick the checkbox next to the channel you want to publish products to. Click Save publication targets. The selected channel will be shown with a selected chip.

✅

Your connector is now fully configured and ready to receive product exports.

Phase 3 — Publish a Product
Publishing

Open a Product in Vexa PIM

Navigate to Products in the sidebar. Find a product in Approved or In Review status. Click its title to open the product detail page.

Publishing

Check the Quality Tab

Click the Quality tab. Review the Compliance Validation section. Ensure there are zero blocking errors for Shopify. Warnings are informational and do not prevent publishing.

ℹ️

Common blocking issues: missing primary HTTPS image (mainImageUrl), missing title, missing SKU. Fix these before proceeding.

Publishing

Trigger a Shopify Export Job

On the product detail page, click Export to Shopify (or the channel publish button). Confirm the target connector shows the alias you set up (e.g. main-store). Click Submit. A job is queued immediately.

Verify

Monitor the Export Job

The job status transitions: QUEUED → PROCESSING → SUCCESS (or ERROR). You can watch progress in the Submission History panel on the product page or in Jobs from the sidebar. Processing typically completes within 10–30 seconds.

⚠️

If the status is ERROR, click the job row to see the full error message. Common causes: zero selling price, duplicate SKU in Shopify, or rate-limit retry in progress.

Verify

Confirm the Product in Shopify Admin

In Shopify Admin → Products, search for the product by title or handle. Confirm:

• Status is Active  ·  Correct price and SKU  ·  Published to your chosen channel  ·  Primary image present

🎉

Your product is live in Shopify. Repeat Steps 11–15 for each product, or use Bulk Edit to queue multiple exports at once.
