# @pim1/db

Prisma schema package for PIM1 catalog domain.

## Commands
- `npm run prisma:generate --workspace @pim1/db`
- `npm run prisma:migrate --workspace @pim1/db -- --name init`
- `npm run prisma:studio --workspace @pim1/db`

## Environment
Set `DATABASE_URL` (PostgreSQL) at repo root `.env`.
