Core User Workflows:
1) Create Product
- UI route: /catalog/products
- API: POST /api/v1/catalog/products
- Compliance validation triggered after create.

2) Edit Product
- UI route: /products/[id]
- API: PATCH /api/v1/catalog/products/:id
- Requires expectedVersion.

3) Manage Categories
- UI route: /catalog/categories
- API: /api/v1/taxonomy/categories
- Admin-restricted writes.

4) Manage Attributes
- UI route: /catalog/attributes
- API: /api/v1/taxonomy/categories/:id/attributes
- Admin-restricted writes.

5) Manage Variants
- UI route: /products/[id] (variants tab)
- API: /api/v1/catalog/products/:id/variants

6) Import Catalog
- UI route: /operations/imports
- API: /api/v1/bulk-import/*

7) Bulk Edit
- UI route: /operations/bulk-edit
- API: /api/v1/bulk-edit/preview, /apply, /operations

8) Connector and Channel Operations
- UI route: /channels/connectors and /channels/submissions
- API: /api/v1/connectors/* and /api/v1/submissions/*

9) Quality Inbox and Validation
- UI routes: /quality/issues, /quality/validation, /quality/completeness
- API: compliance and issue inbox endpoints

10) Plan and Governance
- UI route: /admin/plan and /admin/audit
- API: /api/v1/billing/* and /api/v1/audit/logs
