# Workflow Validation Test Script

## Test Objective
Validate usability of the 4 core workflows before engineering build.

## Participants
- Minimum 5 target users
- Mix: small seller, mid seller, aggregator

## Tasks

### Task 1: Create Product With Variants
Success condition:
- User creates parent product and at least 2 variants without facilitator help.

### Task 2: Fill Category Attributes + Compliance
Success condition:
- User completes required attributes and resolves at least one validation error.

### Task 3: Map Product to Channel and Run Validation
Success condition:
- User maps product fields for a selected channel and reaches validation pass or clear fix path.

### Task 4: Bulk Import and Repair
Success condition:
- User uploads sample file, identifies row-level issues, and completes one repair cycle.

## Metrics
- Task completion rate
- Time on task
- Error count
- Help request count
- User confidence rating (1-5)

## Pass Criteria
- At least 80% average completion rate
- No critical blocker across all participants
